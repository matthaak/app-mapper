# Mapper

The App Mapper application itself (`src/modules/mapper/`). It combines the other modules: the [Canvas](canvas.md) as the workspace background, [MD Editor](md-editor.md) windows for files, and NeXT-style [Widgets](widgets.md) for every control.

## What it owns

* **The workspace** (`app.ts`, `MapperApp`) — an `NxDesktop` whose background layer is a `CanvasView`, with the panels over it, and the open files in the tabs of an `EditorDock` at its right — or, with View ▸ Use Editor Windows (off by default, remembered), in editor windows over it. View ▸ Theme switches the whole app between Classic (NeXT) and Modern (see [Widgets](widgets.md)){++, Modern unless the user has chosen Classic++}{>>Claude 2026-11-18 15:35: Changed: Modern is the default theme<<}, remembered. The canvas spans the whole window, under the dock; its viewable area is what lies left of the dock's bezel (`EditorDock.reserve`) — open, closed, or with editor windows, which then have that room — so opening or closing the dock, or switching to editor windows, never moves the diagram. When the window is resized or the bezel dragged, the canvas pans to keep what was in the middle of its viewable area there (`layoutDock`). Reset View fits the whole diagram in the viewable area, and files put on the canvas go in its middle. The view is saved per project with the viewable area's middle, and restored around the middle it has now. The window's title names the dock's front file ("Title — file.md") while the dock is open, else the project file (`updateTitle`). It owns the application menu: `menuSpec` describes File (projects — Rescan Project, and Refresh All, which reopens the project from disk, reverting unsaved changes after a native warning, with the same files open; Set Up for AI Agents; New MD File… and Add MD File, the project's Markdown files as "Title — folder/path", greyed out once on the canvas; Save, Save All), Canvas (the canvas commands, enabled and checked from the canvas's state), Edit, View and Window, and sends it to the host whenever what it shows changes; the host's menu sends back commands (`menuCommand`). In a browser, which has no application menu, the same menus are shown as a NeXT menu. It opens and creates projects, keeps the canvas, the files and the editors in step, tracks what is unsaved, saves, and recovers unsaved changes after a crash. It reaches files and the application menu through a host (`host.ts`): the Electron main process, or the dev server in a browser.
* **The look** — the canvas in NeXT dress (`mapper.css`): the desktop purple with faint, lighter grid lines, nodes in the windows' grey framed in black, solid grey 2px hierarchy lines and dashed white dependencies; a selection is a heavier black frame.
* **Nodes** — one per file, its id being the file's project path. The label is the file's title, the sublabel its file name; a node whose file has disappeared is drawn faded and dashed.
* **Dependencies** — rebuilt from the files on the canvas whenever any file changes, with ids made of source and target paths so a selection survives the rebuild. Canvas edits to dependencies are turned into edits of the source file's text.
* **Projects** — picked in the NeXT Open and New Project panels, which list only valid project files. Opening one reads it (checking it again with `parseMap`, for a path typed in), scans its folder, and shows its map; the last one opened is reopened at launch. New Project writes an empty map (`{"version": 1, "nodes": []}`) and opens it; with Create root README.md file on (it is greyed out for a folder that has one), it first writes README.md, titled with the folder's name, and puts it on the map; with Set up for AI agents on (remembered when turned off; greyed out for a folder that has this version's skill), it sets the project up for AI agents. Leaving a project with unsaved changes asks: Don't Save, Cancel or Save All.
* **Saving** — only on request: Save (the front editor's file, else the project file), Save All, and each editor's Save button. A Markdown file is unsaved while its text differs from what was last read or written; the map, while the project file this app would write differs from the one on disk. A bullet marks unsaved changes: in the page (window) title for the project file, on a node's label and its editor's title for a file. Pan and zoom are remembered per project on this computer, not in the project.
* **Auto-recovery** — 0.8 s after the last change, everything unsaved (the map's text, each unsaved file's text) is handed to the host's recovery store, and dropped from it once all is saved. Closing after the user's answer drops it too, so a record left behind means the app didn't close cleanly; opening that project offers Recover (the changes come back unsaved) or Discard. A reload keeps the record as well, so it is offered after one.
* **AI agents** (`agents.ts`) — App Mapper's skill for coding agents, from the template `agent-skill.md.tmpl` (the project file's name and `SKILL_VERSION` filled in), written to the project's `.claude/skills/app-mapper/SKILL.md`, with a block pointing to it in `AGENTS.md` between `<!-- app-mapper -->` markers (the rest of that file kept). `agentSetup` says how far a project is set up: none, old (an older version), stale (differs from what this version writes) or current. File ▸ Set Up for AI Agents writes both, enabled unless current; opening a project whose skill is old offers to update it, asked once per version. Raise `SKILL_VERSION` whenever the template changes.
* **Rescanning** — the folder is re-read when the browser window regains focus (and on Rescan), so files added or edited elsewhere appear. Files with unsaved edits keep their in-memory text (and stay listed even if deleted on disk).

## Panels and windows

* `editor-window.ts` — an `NxWindow` holding a `MarkdownEditor` (with its Save button), titled "name — folder" with a bullet while unsaved, without a miniaturize button. An editor opens with **Track Changes** on when its file already has additions, deletions or comments (`hasRevisions`), else off; with it on, what you type becomes your additions and what you delete your deletions. Everything is attributed to your OS user name (else "Me"). {++Show Spelling Errors is one setting for every editor: toggling it in one turns it on or off in all open editors, and it is remembered (on by default).++}{>>Claude 2026-11-18 12:37: Added: one spelling setting for all editors<<}
* `open-panel.ts` — Open Project and New Project, in the desktop app and a browser alike: a lazily loaded `NxBrowser` of folders and the valid project files in them (the host's `list`) — from the root, or on Windows from This PC, listing the host's `roots` (every drive, mapped ones too) — with the file's path, laid out with `pin` so the panel resizes. New never replaces an existing file, and adds Create Folder… (the host's `mkdir`, asked for in `namePanel`) and the README and AI agents switches (`NxSwitch`).
* `new-file-panel.ts` — New File: title, name (derived from the title until edited) and folder (an `NxBrowser` of the project's folders, the root by default). Until a title or name is typed, it suggests README.md, titled with the folder's name, for a folder without one; else Untitled.
* `dialogs.ts` — alerts and choice panels (unsaved changes, recovery, the welcome panel).
* `editor-dock.ts` — the paneled UI's dock: a NeXT tab per open file, the front one joined to its editor (toolbar and all) below, and on its left a resizer drawn like a window's resize bar on end (drag: resize, its share of the window's width remembered — 40% by default; click: close the drawer). Closed — and when its last file is closed — only a "Files (n)" drawer tab shows against the right edge, which can be dragged up and down (its place kept as a share of the height) and clicked to open it again; opening a file opens it too. Its bezel's place, open or not, marks the edge of the canvas's viewable area (`reserve`).
* `editor-window.ts` — an open file's MD Editor: `EditorWindow` (a NeXT window) or `EditorTab` (a dock tab). Switching View ▸ Use Editor Windows moves open files between the two.
* `frames.ts` — windows come back where they were left, across launches, on this computer (in the page's local storage): the browser's NeXT menu, Open Project and New Project, New MD File, and each file's editor window (per project). Sizes are kept for resizable windows only.
